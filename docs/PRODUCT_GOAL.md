# Compass 产品目标与演进路线

状态：开发目标，2026-11-15 确认

## 一句话目标

Compass 是人与 AI 共同设计开发的「实时交互纪要与低认知负载项目掌控台」：它像 AI 开发过程中的实时会议助手一样，透明记录你与 Agent 的每一次行动轨迹、思路脉络与待定决策，让你无需逐行阅读晦涩的 IDE Git diff 即可看清全貌、一键定案项目基准并精准检索溯源；当项目从个人原型演进到多人团队协作时，同一套账本可以无缝切换升维为可追溯的团队共识。

## 双路线使用模型（Solo-First → Team）

为了兼顾独立开发者与多人协作团队，Compass 在前端提供可直接切换、各自特性优化的两条使用路线，底层共享同一套不可篡改的证据账本：

1. **个人开发路线（Solo Mode，基本盘）**：
   - 面向单人使用 AI 编程（Vibe Coding / Agent 结对开发），**零“团队审批”仪式感**，署名输入一次即本地记忆。
   - **核心视图聚焦**：「实时纪要 · 待定思路」（刚刚改了什么、哪些前提尚未验证、哪几个分支还在犹豫待定）↔「项目基准 · 已定案」（我亲手拍板确认过的核心决策与目标）。
   - **一键续写快照**：跨天、切换对话窗口或上下文压缩前，生成结构化的个人上下文续写快照。

2. **团队协作路线（Team Mode，自然扩展）**：
   - 当一个项目有多个成员或并行 Agent 会话介入时一键开启。
   - 展开多成员在场状态栏、分歧立场并列对照裁决矩阵、待负责人晋升队列，以及面向协作流转的交接简报导出（Issue / PR / PRD）。

## 核心动作闭环（同一工作台内完成）

1. 打开已有项目或零配置接入本地工作区（Antigravity / Codex / MCP / 项目文档）。
2. 在**实时纪要**中直观看到自己与 Agent 的行动轨迹、待定决策、Todo 与未验证前提，告别晦涩的代码流水账 diff。
3. 将任意已核对的待定思路**一键定案为项目基准（Solo）或确认为团队共识（Team）**，只追加确认记录，推翻前的历史永远保留。
4. 点开或光标悬停任意 `[证据 ID]` 徽标，**10px 邻近预取并即时透视原始会话发言、命令记录、作者、时间与来源当前性**。
5. 围绕项目提出“为什么现在是这个状态”“下一步做什么”“哪几处有未验证假设”，快速得到带精准引用与证据缺口标注的回答。

## 产品边界与演进路线（v1.0 vs vNext）

### v1.0（当前开源版本：可信赖的实时记录与确定性掌控台）
- 本地优先、零第三方运行时依赖的追加式证据账本与个人/项目/团队分层视图；
- 真实宿主与本地监听接入（MCP 4 工具、`TranscriptWatcher`、`--scan` 文档与纯 AST 代码结构索引）；
- Solo / Team 双路线工作台、悬停精确引文溯源与双向认知资产导出（Markdown 简报 / Issue / PR / PRD）；
- 严守红线：不虚构结论、不展示隐藏模型思维链、不自动篡改已定案事实。

### vNext（后续演进：模型主动巡检与项目健康度洞察 Proactive Insights）
- 引入轻量模型巡检能力，在不篡改客观账本的前提下，结合证据与代码结构图向开发者发出**主动质量提醒**，帮助非科班或高频 AI Coding 开发者尽早发现隐性失控：
  - **样式与交互散落预警**：提示跨页面出现重复的 CSS / 交互实现或违反统一规范的局部写法；
  - **未验证假设拦截**：提醒某项核心实现正建立在未经实测或未经定案的猜测之上；
  - **重复逻辑与冗余残留提醒**：标记功能重叠的模块或长期未使用的孤立代码节点，辅助及时“止血重构”。

## 验收与可靠性基线

- 两个不同项目可在同一工作区注册并互不混淆，支持重启恢复与只读跨项目预览。
- 缺失或损坏的注册表不会覆盖任何项目的规范状态文件。
- `--list-projects` 与 `--sample` 可在无外部凭据下确定性运行。
- 原始证据只追加不覆盖，所有自动化单元与 Node VM 契约测试保持全绿通过。
